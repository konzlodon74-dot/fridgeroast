## What it does

`main.py` (Python 3, no network, no dependencies) writes a single original
roast line about a smart fridge — a firmware update that bricks the ice maker,
which then goes on strike — to `/output/entry.txt`. The line is 158 characters,
one line, plain UTF-8.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Output is deterministic: repeated runs produce byte-identical files.
